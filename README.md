# Rehobolts Power Solutions — Local Website Files

## Run locally
1. Extract this ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox or Safari.
3. An internet connection is required for Google Fonts and the remote Unsplash photos.

## Deploy
This is a static HTML/CSS/JavaScript site. You can upload the folder to a static host or use Vercel:
- Install Node.js and Vercel CLI if you want to deploy from your computer.
- Run `vercel` in this folder and follow the prompts.
- To publish to the existing Vercel project, make sure you are logged into the correct Vercel account and select `rehobolts-power-solutions`.

## Important implementation notes
- The appliance calculator and solar estimator run in the browser and use clearly stated illustrative assumptions.
- The enquiry form stores submissions in the browser's localStorage on that device only. It does not send enquiries to Rehobolts.
- No admin dashboard, database, authentication, product inventory backend, or server-side lead capture is included in this local starter package.
- Product prices and technical specifications are intentionally not fabricated. Confirm them with the business before publishing.
- Replace/add the verified business phone, WhatsApp, email, logo and product specifications before launch.
